# 🏛️ نظام بلدي أجير — Balady Ajeer System

**بوابة خدمات إلكترونية لإدارة عقود أجير والشهادات الصحية**

---

## 📌 ما هو النظام؟

نظام **بلدي أجير** هو موقع إلكتروني يتكون من **نظامين فرعيين**:

| النظام | الوصف |
|--------|-------|
| **نظام العقود (أجير)** | إنشاء عقود عمالة مؤقتة، طباعتها كـ PDF، توليد رموز QR، والتحقق من صلاحيتها |
| **الشهادات الصحية** | إصدار شهادات صحية للعاملين، طباعتها، والتحقق من صلاحيتها عبر QR |

---

## 🏗️ طبيعة النظام التقنية

| البند | التفاصيل |
|-------|----------|
| **النوع** | موقع Static — ملفات HTML/CSS/JS فقط |
| **Backend** | ❌ **لا يوجد** — لا يوجد سيرفر Node.js أو PHP يشتغل |
| **قاعدة البيانات** | **Supabase** (PostgreSQL سحابي) — مستضاف خارجياً |
| **الاتصال بالداتابيز** | مباشرة من المتصفح عبر Supabase JS SDK |
| **الاستضافة المطلوبة** | أي Web Server يقدّم ملفات ثابتة (Nginx / Apache) |

> **ببساطة**: الموقع = مجلد ملفات HTML يُفتح في المتصفح، والمتصفح نفسه هو اللي بيتصل بقاعدة البيانات.

---

## 🔄 كيف يعمل النظام؟

```
┌─────────────────────────────────────────────────────┐
│                  متصفح المستخدم                      │
│                                                     │
│   login.html → index.html → ajeer/ أو health/       │
│                                                     │
│   shared/js/config.js   ← يحتوي إعدادات الاتصال     │
│   shared/js/supabase-config.js  ← يبدأ الاتصال      │
│   shared/js/auth.js     ← يحمي الصفحات بتسجيل دخول │
│                                                     │
└──────────────────────┬──────────────────────────────┘
                       │ HTTPS API Calls
                       ▼
              ┌────────────────┐
              │   Supabase     │
              │  (PostgreSQL)  │
              │  سحابي خارجي   │
              └────────────────┘
```

### مسار المستخدم:
1. يفتح الموقع → يتحوّل لصفحة **تسجيل الدخول**
2. يسجّل دخول → يظهر **اختيار النظام** (عقود أو شهادات)
3. يختار النظام → يدخل **لوحة التحكم** ويبدأ يشتغل
4. العقود/الشهادات فيها **رابط تحقق عام** يُفتح بدون تسجيل دخول (للمراجعين)

---

## 🗄️ قاعدة البيانات

النظام يستخدم **3 جداول** في Supabase:

| الجدول | الغرض | ملف الإنشاء |
|--------|-------|-------------|
| `contracts` | عقود أجير (بيانات العامل + المنشآت + التواريخ) | `supabase_setup.sql` |
| `health_certificates` | الشهادات الصحية (بيانات حاملها + المنشأة + الصلاحية) | `supabase_setup.sql` |
| `users` | المستخدمين (اسم مستخدم + كلمة مرور) | يُنشأ يدوياً |

## ⚙️ ملف `generate-config.js`

هذا السكريبت يقرأ ملف `.env` وينتج ملف `shared/js/config.js` الذي يحتاجه الموقع.

```
.env  →  node generate-config.js  →  shared/js/config.js
```

يُشغَّل **مرة واحدة** بعد وضع ملف `.env` على السيرفر، أو كلما تغيرت قيمه.

## 🌐 التوجيه (Routing) المطلوب

| الرابط النظيف | يشير إلى |
|---------------|----------|
| `/` | `/shared/index.html` |
| `/login` | `/shared/login.html` |
| `/ajeer` | `/ajeer/ajeer-dashboard.html` |
| `/health` | `/health/health-dashboard.html` |

> باقي الصفحات تُفتح بمسارها المباشر (مثل `/ajeer/verify.html?id=xxx`).

---

## 📝 ملاحظات مهمة

- **لا يحتاج Node.js للتشغيل** — فقط لتوليد `config.js` مرة واحدة
- **لا يحتاج قاعدة بيانات محلية** — Supabase سحابي ومستضاف خارجياً
- **صفحات التحقق عامة** — `verify.html` و `health-verify.html` لازم تكون بدون حماية لأن المراجعين يفتحوها عبر QR
- **ملف `config.js` مستثنى من Git** — لأنه يحتوي مفاتيح ويُولَّد على السيرفر
