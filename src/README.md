# 🏛️ نظام بلدي أجير — Balady Ajeer System

**بوابة خدمات إلكترونية لإدارة عقود أجير والشهادات الصحية**

---

## 📌 ما هو النظام؟

نظام **بلدي أجير** هو موقع إلكتروني يتكون من **نظامين فرعيين**:

| النظام | الوصف |
|--------|-------|
| **نظام العقود (أجير)** | إنشاء عقود عمالة مؤقتة، طباعتها كـ PDF، توليد رموز QR، والتحقق من صلاحيتها |
| **الشهادات الصحية** | إصدار شهادات صحية للعاملين، طباعتها، والتحقق من صلاحيتها عبر QR |

---

## 🏗️ طبيعة النظام التقنية

| البند | التفاصيل |
|-------|----------|
| **النوع** | موقع Static — ملفات HTML/CSS/JS فقط |
| **Backend** | ❌ **لا يوجد** — لا يوجد سيرفر Node.js أو PHP يشتغل |
| **قاعدة البيانات** | **Supabase** (PostgreSQL سحابي) — مستضاف خارجياً |
| **الاتصال بالداتابيز** | مباشرة من المتصفح عبر Supabase JS SDK |
| **الاستضافة المطلوبة** | أي Web Server يقدّم ملفات ثابتة (Nginx / Apache) |

> **ببساطة**: الموقع = مجلد ملفات HTML يُفتح في المتصفح، والمتصفح نفسه هو اللي بيتصل بقاعدة البيانات.
